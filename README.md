# Práctica de CSS

Proyecto de práctica donde aprendo a maquetar páginas web
responsive con Flexbox, Grid y unidades relativas.

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y unidades relativas)
- Git y GitHub

## Qué estoy aprendiendo

- Distribuir elementos con Flexbox
- Crear cuadrículas con Grid
- Escribir CSS ordenado y fácil de mantener

## Cómo verlo

1. Descarga el proyecto (botón verde **Code** > **Download ZIP**)
2. Abre `index.html` en tu navegador
